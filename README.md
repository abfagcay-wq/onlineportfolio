# Personal Website - Study Flow

A comprehensive personal website featuring an interactive flashcard system and study tools designed to enhance learning and productivity.

## Features

### 🎯 Main Components
- **Interactive Dashboard**: Central hub for navigating study materials
- **Flashcard System**: Advanced flashcard application with multiple study modes
- **Grade Selection**: Educational content organized by grade levels
- **Subject Trees**: Hierarchical organization of study topics
- **Growth Hub**: Personal development and progress tracking

### 📚 Study Tools
- **Enhanced Flashcards**: 
  - Multiple study modes (review, practice, test)
  - Progress tracking and statistics
  - Customizable card categories
  - Spaced repetition algorithm
- **English Learning**: Dedicated section for language studies
- **Subject Navigation**: Tree-based content organization

### 🎨 Design Features
- Modern, responsive UI with smooth animations
- Dark/light theme support
- Mobile-friendly design
- Accessibility-focused interface

## Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional but recommended)

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/personal-website.git
   ```

2. Navigate to the project directory:
   ```bash
   cd personal-website
   ```

3. Open `index.html` in your web browser or serve with a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Or simply open index.html directly
   ```

## Usage

1. **Start Learning**: Open the main dashboard and select your grade level
2. **Choose Subject**: Navigate through the subject tree to find your topic
3. **Study Flashcards**: Use the enhanced flashcard system with various study modes
4. **Track Progress**: Monitor your learning statistics and improvements
